# 회원·동문 검색·게시판 개발

## 확정 요구사항

- 장학사업은 추진 중 유지.
- 로그인 회원만 기수·이름으로 동문 검색. 결과는 이름, 기수, 졸업연도, 사이트 가입 여부만 제공.
- 자유게시판은 로그인 회원 누구나 작성, 공개 열람. 작성자 또는 관리자만 수정·삭제.
- 공지·행사·사진/영상·회무 게시판은 관리자만 작성·수정·삭제, 공개 열람.
- 총괄 관리자 SUPER_ADMIN은 DB에서 최대 1명. 총괄 관리자만 ADMIN 권한 부여·회수.
- 회원가입 필드와 약관·개인정보 동의, 선택 SMS/이메일 동의 저장. 발송 기능은 이번 범위 아님.
- 개인정보 담당자/연락처는 사용자 답변에 따라 미정. 법률 검토 자료와 운영 전 확정 항목을 문서화.
- 동문 검색 공개 동의는 별도 선택 사항. 동명이인 계정을 명부에 자동 연결하지 않음.
- 기존 자료·메인 스타일을 유지하면서 실제 데이터 화면으로 연결.

- 제공 HWPX에서 20~97회 4,859개 원문 항목을 추출했다. 1~19회 제외, 운영자 승인에 따른 44회 괄호 누락 정정 1건, 62회 불완전 이름 1건 보류 후 로컬 DB에 4,858건 등록했다.

- 실제 명부, 정정 JSON, 대조 CSV 및 SQL은 Git 제외 경로 `.harness/`에만 보관한다. 회원 계정 자동 생성·연결, 운영 DB 수정 및 push는 하지 않았다.
- 최종 `node scripts/verify.mjs all` 통과: 브라우저 60개, Java 단위/통합 18개, 추출 도구 12개, 격리 PostgreSQL 등록 SQL 6개 및 Compose/배포 모의 검사. 기존 이미지 최적화 권고 6건과 Gradle 호환성 권고는 남아 있다.

## 회원 자동 연결 및 관리자 확인 (2026-10-14)

- 회원가입 시 이름·기수가 일치하는 명부가 정확히 1건이고, 다른 회원과 연결되지 않았으며 동일 이름·기수의 다른 활성 회원도 없으면 자동 연결한다. 일치 명부가 없으면 연결 없이 가입한다.
- 동명이인 명부, 이미 사용 중인 명부, 동일 이름·기수의 복수 계정은 관리자 화면의 `회원 연결 확인` 탭으로 보낸다. 관리자는 지역·졸업연도·연결 상태를 비교한 뒤 본인 확인을 체크하고 연결 확정 또는 연결 제외 처리한다.
- 확인 대기·연결 완료·연결 제외 목록, 이름 검색, 페이지 이동, 오류 재시도 및 동시 처리 충돌 안내를 제공한다. 일반 회원은 확인 API에 접근할 수 없다.
- V5는 확인 이력 테이블을 추가하고, 기존 미연결 회원 중 일치 명부가 있는 회원을 확인 대기로 등록한다. 기존 회원의 연결을 자동으로 바꾸지 않는다. 이후 별도 명부 추가만으로 기존 회원을 자동 연결하거나 확인 대기에 추가하지는 않는다.
- 기존 관리자 명부 편집에서도 연결 중복과 오래된 화면의 덮어쓰기를 차단하고 확인 이력을 동기화한다. 이름·기수 일치는 실명·휴대폰 본인인증을 대신하지 않으며 개인정보 공개 동의와 권한은 기존대로 유지한다.
- `node scripts/verify.mjs all` 통과: Java 단위·DB 통합 25개, PC/모바일 브라우저 68개, 추출 도구 12개, 격리 PostgreSQL 등록 SQL 6개 및 Compose/배포 모의 검사. 마지막 모바일 목록 조정 후 `node scripts/verify.mjs frontend`도 재통과했다.
- PC·모바일 목록 및 확인 화면 캡처를 확인했다. 로컬 개발 DB에 V5 적용을 확인했고 실제 브라우저 가입·세션·검색·사진 첨부·게시글 작성/수정·관리자 접근 거부 검사도 통과했다. 생성한 가상 계정·게시물·첨부파일은 삭제했다.
- 기존 이미지 최적화 권고 6건과 Gradle 호환성 권고는 남아 있다. 이번 변경은 아직 commit·push·운영 배포하지 않았다. 운영 반영 시 앱 이미지 배포로 V5가 적용되며 명부 SQL 재등록이나 서버 Compose 변경은 필요하지 않다.

- 운영 가입 가능 설정을 코드에서 false로 관리한다. 공개 상태 조회 API와 중단 안내를 추가했으며, 상태 미확인·조회 실패 시 폼을 열지 않는다. 이미 열린 폼에서도 서버가 가입을 거부한다. dev/test는 가입 가능 상태를 유지한다.

- 기존 ESLint 이미지 최적화 권고 6건과 Gradle 차기 주요 버전 호환성 권고는 남아 있다. 이 검증은 전체 애플리케이션·컨테이너의 보안 감사나 법률 검토 완료를 의미하지 않는다.
- 예제 설정의 로컬 개발 Compose를 시작하고 `http://localhost:8088`의 화면/API 및 실제 Next.js 16.4.3 실행을 확인했다. `node scripts/smoke-local.mjs`로 실제 브라우저 가입·세션·검색·사진 첨부·게시글 작성/수정·관리자 작성 거부를 검증했고 생성한 가상 계정·게시물·첨부파일은 삭제했다. 개발 환경은 가입 가능 상태이며 운영 데이터·백업은 검증에 사용하지 않았다.
- DB 마이그레이션·명부 재등록·서버 Compose 변경은 필요 없다. 아직 commit·push·운영 배포는 하지 않았다. 운영 Nginx 가입 차단과 기존 백업을 유지하며, 승인된 자동 배포 확인 후에만 [운영 작업 기록](operations-status.md)의 임시 차단 제거 절차를 진행한다.
