# 회원·동문 검색·게시판 개발

## 확정 요구사항

- 장학사업은 추진 중 유지.
- 로그인 회원만 기수·이름으로 동문 검색. 결과는 이름, 기수, 졸업연도, 사이트 가입 여부만 제공.
- 자유게시판은 로그인 회원 누구나 작성, 공개 열람. 작성자 또는 관리자만 수정·삭제.
- 공지·행사·사진/영상·회무 게시판은 관리자만 작성·수정·삭제, 공개 열람.
- 총괄 관리자 SUPER_ADMIN은 DB에서 최대 1명. 총괄 관리자만 ADMIN 권한 부여·회수.
- 회원가입 필드와 약관·개인정보 동의, 선택 SMS/이메일 동의 저장. 발송 기능은 이번 범위 아님.
- 개인정보 담당자/연락처는 사용자 답변에 따라 미정. 법률 검토 자료와 운영 전 확정 항목을 문서화.
- 동문 검색 공개 동의는 별도 선택 사항. 동명이인 계정을 명부에 자동 연결하지 않음.
- 기존 자료·메인 스타일을 유지하면서 실제 데이터 화면으로 연결.

## 검증 기록 (2026-10-14)

- 실제 연결 검사에서 발견한 준비 전 폼 제출에 대한 회귀 검사를 추가한 뒤, 공통 하네스 전체 빌드·테스트·Compose·배포 모의 검사를 다시 통과했다. 마지막 게시판 목록 API 정합성 수정 후 백엔드 검사도 재통과했다.
- DB 통합 11개 + 단위 5개, PC/모바일 브라우저 24개 통과. 회원·검색·게시판·관리자·약관·공개 화면과 준비 전 제출 차단을 검사한다.
- Docker 개발 전체 연결: 실제 가입/세션/동문 검색/사진 첨부/글 작성·수정/관리자 작성 거부 성공. 생성한 가상 회원·게시글·첨부파일은 삭제 완료.
- 기존 로컬 개발 DB에서 Flyway baseline 0 및 V1/V2 적용 성공. 운영 DB와 운영 서버는 변경하지 않았다.
- PC·모바일 캡처 확인. 메인 제목 대비 수정, 폼·테이블 가로 넘침 검사.
- Next.js 16.4.0, PostCSS 8.5.30으로 업데이트. 실행 의존성 npm audit 0건. 개발 검사 도구의 전이 의존성 경고 5건은 남아 있으며 강제 하위 버전 변경은 하지 않았다.
- ESLint 이미지 최적화 권고 8건, Gradle 차기 주요 버전 호환성 권고는 오류가 아니며 남아 있다.
- 운영 공개 전 담당자/위탁/보유 정책 확정, 총괄 관리자 초기화, 서버 Compose 별도 반영 필요. 운영 배포·원격 push는 실행하지 않았다.

- 소개 10개 화면에 공통 왼쪽 메뉴·현재 위치·선택 표시를 적용했다. 모바일은 가로 메뉴이며 선택 항목이 자동으로 보인다.
- 학교 사진, 시기별 연대표, 직책별 임원 명부, 회칙 목차, 학교 현황 펼침 영역, 교가 악보와 지도 링크를 정리했다. 기존 원문 및 기록은 보존한다.
- 당시 준비되지 않은 공식 회장 인사말·총동문회 연혁·역대 회장 자료는 준비 중으로 명시했다. 인사말은 아래 추가 자료 반영에서 전문으로 교체했다.
